ARCHITECTURE & SIGNAL CHAIN

4×4 SPATIAL MULTIPLEXING

Each unit drives four antenna elements on the same carrier frequency. At the receiver, every channel r measures a linear combination of the transmitted element signals xk weighted by the complex propagation paths Hr,k. Once the 4×4 channel matrix H is estimated from the preamble, the receiver separates the active streams as long as the enabled RX channels outnumber or equal the active TX elements and the columns of H are sufficiently independent.

PHASE-CODED JTAG TRANSMITTER

The DSI baseband generator outputs a continuous +500 kHz tone above the RF LO. Data is modulated by stepping the FPGA's per-element phase rotators over JTAG rather than modulating the baseband waveform. Two 16-bit FPGA registers control the four elements in pairs (8-bit phase, 256 = 360°): 0x2C sets EL0/EL1 and 0x2D sets EL2/EL3.

One full 4-element update (a chip) requires two JTAG writes of period T (symbol duration 2T, first spectral nulls at ±1/(2T)). Each active element sends differential Gray-coded BPSK (1 bit/chip), QPSK (2 bits/chip), or 8PSK (3 bits/chip) with a π/M per-chip phase rotation so consecutive chips always produce a phase transition. In CDM4 / CDM8 modes, BPSK symbols are spread across 4 or 8 chips by orthogonal Walsh × PN sequences.

FRAME STRUCTURE (1024 JTAG WRITES)

Each frame is dispatched to the fpga-csi driver as a single 1024-write ioctl batch: 16 lead-in writes (repeating the zero-phase tail state) followed by 504 chips (1008 writes, ~6–20 ms on air for T = 6–19.2 µs). Before frame 0 of a burst, the transmitter holds an unmodulated lead tone so the MAX2850 synthesizer settles and the receiver can estimate coarse carrier frequency offset (CFO).

Preamble (24 chips, 48 writes). Fixed phase sequence. Chip 0 flips all four elements by 180°; subsequent writes flip one element of the active pair by 180° and step the other by +90° so a boundary step remains visible even if one element is deeply faded. Least-squares regression over the 48 slot means yields the initial 4×4 channel matrix H.

Header (24 chips, 48 writes). Sent in BPSK with identical bits on all four elements. Encodes the frame mode (SDM/CDM4/CDM8), per-element modulation (OFF/BPSK/QPSK/8PSK), end-of-burst flag, 4-bit sequence number, and CRC-8. The receiver configures its demapper from each header with no prior out-of-band negotiation.

Payload (455 chips, 910 writes) + Tail (1 chip returning all phases to 0°). Carries 24-byte blocks (1B type, 1B length, 20B data, 2B CRC-16): station ID, link feedback, chat fragments, ACKs, and deterministic PRBS filler blocks used for live bit-error-rate (BER) measurement. No FEC is applied; throughput counts only blocks passing CRC-16.

RECEIVER DSP & JOINT BOUNDARY TRACKER

Four 8-bit CSI ADC streams at 37.38 MS/s (hardware saturation near ±39 counts) are mixed down by a 500 kHz + CFO NCO, boxcar-decimated 16× to 2.336 MS/s, and passed through a cascaded boxcar channel filter. A frame start is triggered when the 4-channel vector step between adjacent 8-sample (3.4 µs) windows exceeds the noise- and signal-relative thresholds after a quiet carrier gap. Discrete TX PLL phase spurs (25–280 kHz) are fitted by least squares and subtracted before tracking.

Paced JTAG batches clock writes at a programmed period T (6–18.9 µs via RP1 PIO or RIO), while unpaced batches average ~19.2 µs with occasional multi-period stalls. For each write w, the tracker searches candidate sample boundaries n ∈ [bw−1 + WloT, bw−1 + WhiT] jointly with all Ma × Mb phase hypotheses of the active register pair, combining the 4-channel residual against H with an asymmetric timing prior (wider and capped on the late side). A decision-directed PLL tracks common phase/frequency drift across the frame while LMS + windowed least-squares updates track H. After tracking, payload symbols are extracted by successive interference cancellation and maximum-ratio combining (SIC-MRC).

TDD MAC, POWER CONTROL & RATE ADAPTATION

Both units share one RF channel in half-duplex TDD. While transmitting, local RX samples are discarded and the 8 MB CSI ring is allowed to fill and park its DMA thread so memory bus traffic cannot stall bit-banged JTAG writes. The last frame of a burst sets the header end-of-burst flag, handing the channel to the peer after TURNAROUND ms; if no peer is heard, a random backoff between BEACON MIN and MAX initiates a new burst.

Frames 0, 1, and N−1 of each burst carry a 20-byte feedback block reporting the receiver's per-element symbol SNR, model SNR, 99th-percentile ADC peak level, TX/RX gains, cumulative and per-burst good block counts, and the announced write period T for its next burst. Using this feedback, AUTO TX POWER (ATPC) steers the peer's RX ADC level to PEER RX LEVEL TARGET (backing off 6 dB if above ADC LEVEL LIMIT), and AUTO LINK RATE steps T through the rate table (18.9 ↔ 6 µs) based on per-burst block delivery relative to the goodput break-even threshold Ti / Ti−1.
